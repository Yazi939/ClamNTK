# ClamNTK

ClamNTK (Clam New Tool Kit) — настольная программа для проверки файлов на РЕД ОС. Он вдохновлён ClamTK и ставит графическое окно поверх ClamAV: проверка, базы сигнатур и очистка. В репозитории РЕД ОС нет пакета `clamav`. Если ClamAV на компьютере нет, установщик сам скачивает официальную сборку с clamav.net и ставит её до оболочки.

Проверено на РЕД ОС 7 и 8 с графическим сеансом. Для загрузки пакетов и баз нужен интернет.

## Скачать

На странице проекта нажмите **Code → Download ZIP**, распакуйте архив и откройте получившуюся папку.

Либо в терминале:

```sh
git clone https://github.com/Yazi939/ClamNTK.git
cd ClamNTK
```

## Установить

В папке запустите мастер:

```sh
./Установить\ ClamNTK.sh
```

Тот же мастер открывается двойным щелчком по этому файлу или командой `./cameav-setup`.

Дальше четыре шага.

1. **Приветствие.** Нажмите **Далее**.
2. **Система.** Мастер проверяет, что это РЕД ОС и что есть `dnf`. Строка ClamAV показывает, установлен он уже или будет скачан.
3. **Пакеты.** Сначала в списке ClamAV, затем Qt и polkit, последней строкой — оболочка. Нажмите **Установить** и подтвердите права администратора.
4. **Установка.** Qt и polkit берутся из репозитория РЕД ОС. ClamAV скачивается с clamav.net и ставится раньше оболочки. Пункт **ClamNTK** появляется в меню **Администрирование**.

При первом запуске откройте **Обновления** и нажмите **Обновить базы**. Без пакетов сигнатур проверка не начнётся.

Запустить программу из папки, не ставя её в меню, можно так. Если `clamscan` не найден, ClamAV будет установлен до открытия окна:

```sh
./bin/cameav
```

## Готовый пакет

Если в [выпусках](https://github.com/Yazi939/ClamNTK/releases) есть файл `cameav-….rpm`, его тоже ставит мастер: сначала ClamAV, потом этот пакет. Команда `dnf install ./cameav-*.rpm` сама по себе остановится, пока пакета `clamav` нет в репозитории РЕД ОС.

```sh
sudo dnf install -y ./cameav-*.rpm
```

Снять программу можно из меню «Администрирование» пунктом «Удалить ClamNTK» или файлом `Удалить ClamNTK.sh` рядом с установщиком. Оболочка снимается сразу. Программу ClamAV и базы сигнатур мастер удаляет только если отметить этот пункт. Пароли, закладки и системные файлы не затрагиваются.

```sh
./Удалить\ ClamNTK.sh
```
